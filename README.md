# Diary of Taste - Digital Recipe Book
**ICT 1209 Mini Project**

A modern, fully responsive digital recipe book web application designed to collect and share delicious recipes. Built with HTML, custom CSS, Bootstrap 5, and Vanilla JavaScript, the application provides a smooth and dynamic user experience.

## Key Features

### User Interface & Design
- **Responsive Layout:** Fully optimized for desktops, tablets, and mobile devices using Bootstrap 5.
- **Premium Aesthetics:** Features a carefully curated color palette, beautiful typography (Fraunces, Roboto Slab, Work Sans), and consistent logo branding.
- **Dynamic Animations:** Includes subtle micro-animations, hover effects, and decorative floating background shapes for a highly modern and engaging feel.
- **Smooth Navigation:** Implements smooth scrolling for anchor links and dynamic navbar shadow effects upon scrolling.

### Functionality & Logic
- **Real-Time Recipe Search:** Search for recipes instantly by name on the Recipes page without reloading the browser.
- **Category Filtering:** Filter recipes dynamically using interactive category chips (e.g., Breakfast, Lunch, Dinner, Desserts).
- **Load More System:** Seamlessly load additional recipes into the grid with a single click.
- **Client-Side Form Validation:** Real-time JavaScript validation for the newsletter subscription (Homepage) and the contact form (Contact page), ensuring valid email patterns and required fields before submission.

## Project Structure

- **`index.html`** - The homepage featuring the "Our story" section, featured recipes, and a newsletter signup.
- **`recipes.html`** - The main recipe library equipped with real-time search and category filtering.
- **`recipe-details.html`** - The detailed view for a single recipe, showcasing ingredients, instructions, prep times, and related meals.
- **`contact.html`** - A dedicated contact page featuring a fully validated form to get in touch with the team.
- **`css/style.css`** - Contains all global styles, design tokens (CSS variables), and keyframe animations.
- **`js/script.js`** - A unified JavaScript file powering all interactive logic across the entire application.

## Getting Started

To view the project, simply open `index.html` in any modern web browser. No local server or build tools are required.
